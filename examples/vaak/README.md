## 読むときの勘所

### `??` が唯一の回復手段、`;` が唯一の黙殺手段

```
let pos := search(xs, 42) ?? 0 - 1;    見つからなければ -1 にする
search(xs, 42);                        結果に興味が無い
```

**どちらも書かなければ、領域に paradox が残ってエラーになる。**
「うっかり無視する」ことができない。

### 「無い」に値を割り当てない

```
fn search (…) { … } -> i64;      見つかれば添字、無ければ paradox
```

**-1 を「無い」にしない。** -1 は添字である。
値の空間を削って番兵を作る必要が無い。

### 費用が署名に出る

```
fn fold (r : i32 array alias, …)
```

**`alias` と書いてあれば写さない。** 書いていなければ深く複製される（C-33）。
**読むだけで費用が分かる。**

### 型は混ぜられない

```
n * 10 + (c - 48) -> i64
```

`c` は `u8`、`n` は `i64`。**`->` で型を決める**（C-30）。
暗黙の格上げは無い。

### `alias` に渡せるのは名前だけ

```
let s1 := "3 4 + 2 *";
eval_rpn(s1)                     eval_rpn("3 4 + 2 *") は書けない
```

**同じ呼び出しで同じセルに別名が二つ届かない**ことを保つため（C-87）。
