# 第2章 akasha と `;`

## 2つ以上のことをしたい

1章の終わりに残った問題から始める。

```
1 2
```

これは通らなかった。プログラムという領域に値が2つ置かれるからである。しかしプログラムに2つ以上のことを書けないのでは困る。

必要なのは「値を置かないようにする」手段である。そのための演算子が `;` である。

```
1; 2
```

これは通る。プログラムの値は 2 になる。

`1;` によって、1 という値は**領域に置かれなくなった**。残ったのは 2 だけなので、規則を満たす。

## `;` は値をどこへやるのか

`;` は最低優先度の後置演算子で、左にある値を **akasha** へ潰す。

akasha（आकाश、アーカーシャ）は、色も形も持たないもののことである。REod では:

| akasha | REod |
|---|---|
| 色を持たない | 型を持たない |
| 形を持たない | 値を持たない |

akasha は値ではない。型でもない。**領域を占めない**。だから `1;` を書いても領域には何も置かれず、いくつ並べても規則に触れない。

```
1; 2; 3; 4
```

プログラムの値は 4 である。前の3つは akasha へ潰され、領域を占めていない。

`void` や `never` のような名前を使わないのは、あれらが既存の言語では**型**の名前だからである。akasha は型ではないので、型を連想させる名前を避けている。

## `;` は評価を起こす

ここが `;` の重要な性質である。

> **潰すには、一度作らなければならない。**

`;` は左の式を**評価してから**潰す。したがって `;` は、REod で計算が実際に起きる地点の一つである。

これは驚くべきことに聞こえるかもしれない。「書いてあるのだから当然評価されるのでは」と。

REod ではそうではない。**式は必要になるまで評価されない。** 何が「必要」なのかは3章で詳しく扱うが、`;` はその「必要」の一つである、とだけ今は覚えておけばよい。

言い換えると、`;` は「捨てる」のではなく「**起こしてから捨てる**」。副作用を持つ式を書いてその結果が要らないとき、`;` はその式を実行させる役割を持つ。

## トップレベルでは akasha が残ってよい

`;` で全部潰したらどうなるか。

```
1; 2; 3;
```

最後の `3` にも `;` が付いている。プログラムという領域には何も置かれていない。

これは通る。**ホストは何も受け取らない。**

akasha は領域を占めないので、そこに残っていても構わない。1章で見た「消費されなかった値は外側の領域の値になる」の、値が無い版である。

## 「文」というものが無い

ここまでで、他の言語との大きな違いが一つ現れている。

多くの言語には**文**と**式**という2つの種類がある。`x = 1;` は文であり、`x + 1` は式である。文は値を持たず、式は値を持つ。この区別は構文の側にあって、どちらの形で書いたかで決まる。

REod には**式しかない**。`1;` は「文」ではなく、`1` という式に `;` という演算子を適用したものである。

この違いは実利を生む。他の言語では、文と式の境界は言語設計者が決めていて、書き手からは動かせない。REod では境界を書き手が引く——`;` を書けば値は消え、書かなければ残る。

```
{ 1 + 2 }      % 値は 3
{ 1 + 2; }     % 値は……（3章）
```

そして「文の終わりにはセミコロンを書くもの」という**規則を覚える必要がない**。`;` が何をするかを知っていれば、どこに書くべきかは自分で分かる。値を消したいところに書く。それだけである。

## 少し観念的な言い方

厳密に意味論を追うときにしか要らないが、掴みやすい言い方がある。

`;` は値を akasha へ**溶かす**。色も形も無い状態へ還る。そして akasha が再び形を取ろうとするとき——3章で扱う——何が起きるか。それが REod の中核の仕掛けになっている。

輪廻である。

この比喩は装飾ではなく、3章以降で実際に説明の道具として使う。ここでは「溶ける」側だけを見た。

## この章のまとめ

- `;` は最低優先度の後置演算子で、左の値を **akasha** へ潰す
- akasha は値でも型でもなく、**領域を占めない**。だから `;` を並べても1領域1値の規則に触れない
- `;` は**評価を起こす**。潰すには一度作らねばならないから
- REod の式は必要になるまで評価されない。`;` はその「必要」の一つ（詳細は3章）
- トップレベルでは akasha が残ってよい。ホストは何も受け取らない
- REod に「文」は無い。文と式の境界を、書き手が `;` で引く
