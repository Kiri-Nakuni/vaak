# REod 入門

REod を、REod だけを使う人向けに説明する本。TeX の知識は前提としない。

## この本の約束

REod は PraTeX（TeX の再実装）に埋め込むために作られた言語なので、設計の理由の一部は TeX に由来する。しかし**言語としての REod は TeX を知らなくても学べる**——本書はそちらの側から書く。

本書は次の規律に従う。

> **単純化するならば、単純化していることを隠さない。**

各章の終わりに「**この章でまだ言っていないこと**」を置く。そこに挙がっていることは、後の章で撤回されるのではなく**足される**。本書が「実はこうだった」と前言を取り消すことはない。

これは行儀の問題ではなく、REod の設計原則そのものである。学習者が払った学習コストを、後で嘘だったことにしない。

## 実装状況について

本書は**設計としての REod** を説明する。現在のインタプリタ（Tier 1）は本書の内容をまだ全部は実装していない——特に**1章と2章で扱う領域と `;` の意味論は未実装**である。

したがって本書の例の多くは、今のインタプリタでは動かない。設計と実装の乖離は [言語設計書.md](../言語設計書.md) §6 に一覧がある。
