# Tier 2 実装計画

現行（Tier 1）は [言語設計書.md](言語設計書.md) §6 の通り。仕様が実装に先行しており、**最大の乖離は虚無・paradox・領域が未実装であること**。

`f80` とマクロ層は **Tier 4** 送り。`f80` は 1.8節の理由が生きているが Rust に f80 がなく、ソフトフロートか x87 のインラインアセンブラを要する。マクロ層は言語の字句層に触れるので、他が固まってから。

---

## 順序の根拠

依存関係ではなく**書き直しの量**で決めた。

`;` の意味が「文の終端」から「値を虚無に潰す演算子」に変わると、**ブロックの値の決まり方が全面的に変わる**。これを後回しにして `write` や `hashmap` を先に入れると、入れたものを全部書き直すことになる。したがって **2.1 が最初**でなければならない。

逆に、2.1 はインタプリタを**縮小**する。現在の `eval_block_value` は「残りのトークンがちょうど1つの式として読み切れるか」という先読みで末尾式を判定しているが、`;` の有無で決まるならこの先読みは不要になる。tree-sitter 文法との既知の乖離（editors/README.md）も同時に消える。

---

## 2.1 値と領域の中核 ★最初にやる

**入れるもの**

- 値に **paradox** を追加。実在できず記録もできない
- **`;` を「値を虚無に潰す」演算子**にする。強制を伴う
- ブロックの値＝その領域の値。末尾式の判定を `;` の有無に置き換える
- **領域は値を高々1つ**の強制
- `{}` が paradox を産む
- **フォールバック演算子 `??`**（D-63）。型注釈は値を生成しない
- トップレベルの領域の値がホストへ渡る値になる（現在は `break` の値のみ）

**壊れるもの**

全例・全テストの `;` の位置を見直す必要がある。ただし現行コードの大半は既に正しい形（文は `;` で終わり、末尾式は `;` なし）なので、機械的な変更で済むはず。

**確認したいこと**

- `loop { 5 }` が「不活性」（5 が強制されないので何も起きない）として通ること
- `let x := {};` が paradox の記録として弾かれること
- `hoge()` が何もせず `hoge();` が呼ぶこと

**捨てるもの**

- `eval_block_value` の先読み
- editors/README.md の「文法とインタプリタのずれ」の記述

## 2.2 型と注釈の解釈

**入れるもの**

- 数値型 `i32` `u32` `u8` `u16` `f32` `f64`（`f80` は除外）
- 値が型を持つようにする（現在は i64 のみ）
- **型注釈の解釈**：`let x : T := E;` と `E -> T`（**型を名指すだけ。値は生成しない**）
- 型ごとの既定値関数（`??` の右辺に書く値の慣用形として標準ライブラリが提供する）
- `read() -> T` の返り値型による切り出し（**`-> str` は行、数値型はトークン**）

**入れないもの**

全面的な型検査。ここでやるのは「書かれた注釈を解釈する」ことだけで、推論も検査も Tier 3。

**規約**

> 注釈は名前のあるところに置く。束縛するなら `:`、式の途中で使うなら `->`。

## 2.3 集合体

- `array`（`Array.init`、添字、要素代入）
- **`str` = `u8 array`**、文字列リテラル
- `hashmap`。**欠損キーは paradox を産む**（`d[k]` は「あるはず」、`d[k] ?? v` は「無くてもよい」）
- `pair`

巻き戻しの規律は確保元によらず一様（4.8節）なので、レジスタ層と同じジャーナルに載せる。

---

## 2.4 出力

- `write(fd, 書式, …)`。書式トークン `$s` / `$x`
- 左から順に評価しながら出力（中間バッファを作らない）
- 返り値なし
- 無名標準ライブラリに `printstr` / `printi64` 等の**脱糖を字句どおり**追加
- **`print` を撤去**（暫定実装だった）

---

## 2.5 ループ構文

- `nfor` / `ifor` / `while` / `switch`
- 各構文の `break` / `comp` 方針は 2.1 の領域規則から**導出される**ので、実装は表を写すだけになるはず
- `while` の値は反復回数（μ）。条件は任意の数値型で 0 が停止

---

## 2.6 構造体とメンバ関数

- `typ`（`;` 終端）
- メンバ関数。レシーバの型による解決（4.7節で許されている）
- `.to_str()` 等の標準ライブラリ

- `&=` によるエイリアス束縛
