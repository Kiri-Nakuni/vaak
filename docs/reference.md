# Vaak リファレンス

Vaak（ヴァーク）は、ホストへ埋め込んで短い処理を走らせるための、小さな静的型付き言語です。
ファイルの拡張子は `.vaak` です。スタンドアロンでも実行できますが、入出力やホスト固有の操作は
組み込みの `print` ではなく、ホストが公開した値と関数を通して行います。

この文書は、まずコードを書けるようになるための実用リファレンスです。領域、内界面と外界面、
Akasha、paradox、脱出を一つの像として理解したい場合は、[設計を読むための付録](appendix.md)を
併せて読んでください。厳密な決定の記録は [Vaak 設計判断](vaak/decisions.md)、機能を組み合わせた
実例は [examples/vaak](../examples/vaak/README.md) にあります。

## 1. 導入と実行

### ビルドする

Rust と Cargo が入った環境で、リポジトリのルートから次を実行します。

```console
cargo build --release
```

まずは、試験でも使われている探索の例を走らせられます。

```console
cargo run --release -- examples/vaak/01-探索.vaak
```

結果は `4499` です。ビルド済みの実行ファイルを直接使う場合は、Unix 系では次の形です。

```console
./target/release/vaak examples/vaak/01-探索.vaak
```

Windows では `target\release\vaak.exe` を使います。

### 最小のプログラム

```vaak
let width := 6;
let height := 7;
width * height
```

最後に残った値 `42` が標準出力へ表示されます。最後が `;` で終わり、値が残らなければ、
スタンドアロン版は何も表示せず正常終了します。最上位に残ったものをどう扱うかはホストの仕事です。

### 空白、改行、コメント

改行に構文上の意味はありません。次の二つのコメントを使えます。

```vaak
% 行末までのコメント

%{
  ブロックコメント。
  %{ 入れ子にもできる }%
}%
```

識別子には Unicode の文字、数字、`_` を使えます。ただし先頭を数字にはできません。
文字列リテラルは二重引用符で囲み、`\n`、`\t`、`\\`、`\"`、`\0`、`\x41`、
`\u{3042}` を使えます。

## 2. 値、`;`、`??`

Vaak には「文」と「式」の二分類がありません。代わりに、各領域には最終的に高々一つの値だけを
残せる、という規則があります。

```vaak
{ 1; 2; 3 }       % 1 と 2 を捨て、3 を残す
{ 1; 2; 3; }      % すべて捨て、何も残さない
{ 1 2 }           % 静的エラー。値が二つ残る
```

### `;` は値を捨てる後置演算子

`;` は「行の終端記号」ではなく、左の領域を評価して、その結果を捨てる演算子です。宣言、代入、
値を返さない関数呼び出しが `;` を伴うのは、それらの後に使える値が残らないからです。

```vaak
var total := 0;       % 宣言の結果を捨てる
total += 3;           % 代入の結果を捨てる
notify(total);        % 値を返さないホスト関数の結果を捨てる
```

`1;;` や `{ ; }` も有効です。空の領域に `;` を適用しても、空のままです。

### paradox は「値を要求したが、値が無かった」側

すべての型の式は、通常の値か paradox のどちらかを外側へ置きます。paradox は `null` や
番兵値ではなく、変数のセルへ保存できません。代表的な発生源は次のとおりです。

- 整数や浮動小数の 0 除算
- 配列の範囲外、写像に無い鍵
- `else` の無い `if` が偽だった場合
- どの腕にも一致しない `switch`
- 0 周の `while` と `nfor`
- 空の配列や `str` に対する `.pop()`、欠損要素への `.remove()`
- 値を置かない宣言、代入、関数呼び出し、空の領域

paradox を扱える演算子は、捨てる `;` と、代替値を与える `??` だけです。

```vaak
let item := xs[i] ?? 0;             % 範囲外なら 0
let count := table[key] ?? 0;       % 欠損キーなら 0
lookup(xs, wanted);                 % 結果そのものが不要なら捨てる
```

`??` は左が通常の値なら右を評価しません。左が paradox のときだけ右を評価します。右も
paradox なら、全体も paradox です。

```vaak
1 / 0 ?? 42             % 42
42 ?? expensive()       % expensive は呼ばれない
1 / 0 ?? 2 / 0          % paradox
```

paradox は、値を要求する境界を越えてから回収できません。たとえば、引数の中で発生する可能性が
あるなら、呼び出しの外ではなく引数の位置で受けます。

```vaak
f(xs[i] ?? 0)           % よい
f(xs[i]) ?? 0           % xs[i] が paradox なら f に届く前にエラー
```

`??` の結合は意図的に非対称です。実用上は `table[k] ?? 0 - 1` を
`table[k] ?? (0 - 1)` と読めます。判断に迷う式では括弧で領域を明示してください。

## 3. 束縛と型

### `var`、`let`、`const`

```vaak
var counter := 0;                 % この名前から書き換えられる
let limit : i64 := 100;           % この名前からは書き換えられない
const origin := [0, 0];           % このセルを、どの別名からも書き換えられない
```

`const` の凍結は、その束縛のスコープを抜けるまで続きます。集合体を `const` にすると、その欄や
要素も同じセルの一部なので書き換えられません。

同じ宣言で複数の名前を束縛できます。

```vaak
let dx := x2 - x1, dy := y2 - y1;
```

`:=` は値を書き込みます。集合体は深く複製されるため、写した後の二つは独立です。

```vaak
var a := [1, 2, 3];
var b := a;
b[0] := 9;
a[0]                    % 1
```

複合代入は `+=`、`-=`、`*=`、`/=`、`mod=`、`<<=`、`>>=`、`^=`、`|=` です。
代入は値を残さないので、通常は直後に `;` を書きます。

### 基底型

| 型 | 用途 |
|---|---|
| `u1` | 真偽値。`bool` は同じ型の別綴り |
| `u8` `u16` `u32` | 符号なし整数 |
| `i32` `i64` | 符号付き整数 |
| `f32` `f64` | 浮動小数 |
| `str` | UTF-8 として扱えるバイト列。言語中核ではバイト単位 |
| `f80` | STEEL 方言だけが実行できる拡張基底型 |

`true` と `false` は `u1` のリテラルです。注釈が無い整数リテラルは `i64`、浮動小数リテラルは
`f64` になります。整数リテラルを浮動小数として扱わせることはできないため、`f32` や `f64` が
必要なら `1` ではなく `1.0` と書きます。

暗黙の数値変換はありません。識別子には `:`、式の領域には `->` で型を指定します。

```vaak
let byte : u8 := 65;
let wide := byte -> i64;
let truth := (wide > 0) -> bool;
```

`->` は呼び出しや添字と同程度に強く結合します。長い式の一部だけを変換したいときは、括弧を
使うと読みやすくなります。

整数演算は型の幅で折り返します。整数の `/` と `mod` はユークリッド除算で、余りは常に
`0` 以上 `|除数|` 未満です。

```vaak
-7 / 3       % -3
-7 mod 3     % 2
7 mod -3     % 1
```

浮動小数の NaN と無限大は Vaak の値ではありません。0 除算、オーバーフロー、不定形などで
非有限値になる演算は paradox になります。したがって比較には NaN 特有の例外がありません。

### 集合型は後置で書く

`array` は直前の一型、`map` と `hash` は直前の二型を取ります。連想型は鍵、値の順です。

```vaak
i64 array              % i64 の配列
str i64 map            % str から i64 への写像
str i64 hash           % str から i64 へのハッシュ表
str i64 array map      % str から i64 array への写像
```

型列を左から積み、最後にちょうど一型が残る必要があります。`alias` は型修飾子ではなく束縛の
形なので、`i64 array alias` のように最も外側にだけ置けます。

## 4. 配列、`str`、`map`、`hash`、構造体、ラップ型

### 配列

配列リテラルと `new` のどちらでも作れます。

```vaak
var primes := [2, 3, 5, 7];
var zeros : i64 array := new i64 array(10, 0);  % 長さ 10、初期値 0
```

添字は 0 始まりです。範囲外の読み取りは paradox です。範囲外への書き込みは、成功した代入と
区別できないため実行時エラーになります。

| メソッド | 結果 |
|---|---|
| `.len()` | 要素数を `i64` で返す |
| `.push(v)` | 末尾に追加し、値は返さない |
| `.pop()` | 末尾を削除して返す。空なら paradox |
| `.clear()` | 全要素を削除し、値は返さない |
| `.insert(i, v)` | `i` の位置へ挿入し、値は返さない。範囲外なら paradox |
| `.remove(i)` | `i` の要素を削除して返す。範囲外なら paradox |

破壊的メソッドには `var` のレシーバが必要です。値を返さないメソッドは `;` で捨てます。

```vaak
var stack : i64 array := new i64 array(0, 0);
stack.push(10);
let top := stack.pop() ?? 0;
```

### `str`

`str` は `u8 array` を包んだ型です。文字列リテラルの型は `str` で、NUL 終端はありません。
現在の木を辿る実装と VM では、`.len()`、添字、`.push()`、`.pop()`、`.clear()` がバイト単位で
働きます。

```vaak
let s := "あ";
s.len()                 % 3。UTF-8 のバイト数
s[0]                    % 先頭バイト
s.utf8_len()            % 1。Unicode 符号位置の数
s.utf8_at(0)            % 符号位置を i32 で返す
s.utf8_valid()          % 妥当な UTF-8 なら true
```

`.utf8_len()` と `.utf8_at(i)` は不正な UTF-8 なら paradox、`.utf8_at(i)` は範囲外でも
paradox です。`u8 array` を `str` に包む操作は `new` で、深く複製します。

```vaak
let bytes : u8 array := [65, 66, 67];
let text := new str(bytes);
```

設計上は逆向きの `new u8 array(text)` で剥がすことも決まっていますが、現在の木を辿る実装と VM
にはまだ入っていません。また、`str` に配列の `.insert()` と `.remove()` を使えることも決定済み
ですが未実装です。現時点の移植可能なコードではこれらを使わないでください。

### `map` と `hash`

連想リテラルは `(鍵 => 値, ...)` です。空なら型を明示して `new` します。

```vaak
var score : str i64 map := ("alice" => 10, "bob" => 7);
var empty : str i64 map := new str i64 map();
var cache : str i64 hash := new str i64 hash();

score["alice"] := 11;
let unknown := score["carol"] ?? 0;
cache["answer"] := 42;
```

存在しない鍵の読み取りは paradox です。添字への代入は、既存値の更新にも新しい鍵の挿入にも
使えます。`f32` と `f64` も鍵にできます。`map` では数値順に並び、`-0.0` と `0.0` は
同じ鍵です。STEEL 方言だけが持つ `f80` は鍵にできません。

| メソッド | 結果 |
|---|---|
| `.len()` | 要素数 |
| `.has(k)` | 鍵があれば `true` |
| `.remove(k)` | 削除した値。鍵が無ければ paradox |
| `.keys()` | `map` は鍵順、`hash` は挿入順の配列 |

`map` は並べた配列を二分探索するため検索が O(log n) で、`.keys()` は鍵順です。`hash` は
平均 O(1) で検索し、`.keys()` は挿入順を保ちます。現在の STEEL 実測では数百件が分かれ目で、
小さい表は `map`、識別子表や大きな表は `hash` が向きます。どちらも `.keys()` は新しい配列を
作ることを踏まえてください。

### 構造体

欄には束縛種、型、任意の既定値を書きます。構築時の引数は欄名で渡します。

```vaak
struct Point {
    var x : i64 := 0;
    var y : i64 := 0;
};

var p := new Point(x := 3, y := 4);
p.x += 1;
```

既定値の無い欄は構築時に必須です。存在しない欄、欄の重複、型の不一致は静的エラーです。
構造体の型依存関係は循環できないので、値の中に直接再帰的な構造体を入れることはできません。
必要なら添字やハンドルで関係を表してください。

### ラップ型

`wrap` は基底の表現を再利用しつつ、別の型として扱う宣言です。

```vaak
wrap Meters = i64;

let distance := new Meters(5);       % 包む
let raw := new i64(distance);        % 剥がす
```

包むのも剥がすのも構築なので `new` と書き、深く複製します。上のような基底型を包む、剥がす操作は
木を辿る実装と VM の双方で使えます。

配列や写像を包んだ型へ元の集合型のメソッドを直接使えることも設計上は決まっていますが、現在の
木を辿る実装と VM にはまだ入っていません。利用者定義のメンバ関数はラップ型にも定義できます。
`str` は文字列リテラルと結び付いているため組み込みのままです。

## 5. 関数とメンバ関数

### 自由関数

```vaak
fn square(n : i64) {
    n * n
} -> i64;

square(9)
```

引数の型注釈は必須です。束縛種を省略した引数は `let` です。書き換えるローカルな写しが必要なら
`var n : i64` とします。

非 `alias` 引数は深く複製されます。大きな集合体を写さずに受けたい場合は `alias` を付けます。

```vaak
fn sum(xs : i64 array alias) {
    var total := 0;
    nfor (i, 0, xs.len()) { total += xs[i] ?? 0; };
    total
} -> i64;
```

`-> T` は関数本体の外界面の型です。通常の値 `T` だけでなく、値が無かった場合の paradox も
含みます。`->` を書かない関数は値を返さず、呼び出し側で `;` を使います。

Vaak に組み込みの `return` 文はありません。末尾式が通常の返り値です。途中で関数を抜ける
作用素式 `$return` は、無名の標準ライブラリから提供されます。

```vaak
fn find(xs : i64 array alias, wanted : i64) {
    nfor (i, 0, xs.len()) {
        if (xs[i] == wanted) $return i; fi;
    };
} -> i64;
```

`$return` は専用の構文ではなく、標準ライブラリが内部で
`flow $return = $repeat(break, getdepth());` と定義している作用素式です。このため、通常の
`return` 文を特別扱いせず、使用位置の関数本体までを抜けられます。

関数は局所変数を捕捉しません。関数本体から見えるのは、引数、自身のスコープの宣言、および
周囲で宣言された `fn`、`struct`、`wrap`、`flow` です。関数宣言は同じスコープ全体から見える
ため、前方宣言なしで相互再帰できます。

### メンバ関数

型名と関数名を `.` でつなぎ、第一引数を `self` にします。`self` だけは型が型名から決まるため、
型注釈を書きません。

```vaak
fn Point.norm2(self) {
    self.x * self.x + self.y * self.y
} -> i64;

fn Point.scale(var self, k : i64) {
    self.x *= k;
    self.y *= k;
};

var p := new Point(x := 3, y := 4);
let before := p.norm2();
p.scale(2);
```

読むだけなら `self`、変更するなら `var self` です。レシーバは複製されません。破壊的なメンバ
関数を呼べるのは、書き込み権限を持つ経路だけです。

### パイプ

`|>` は自由関数呼び出しの糖衣です。

```vaak
x |> f(a) |> g()       % g(f(x, a))
```

`.` が型の名前空間からメンバ関数を探すのに対し、`|>` は自由関数だけを呼びます。

## 6. 制御構造

### `if`

`if` 自身が値を返す演算子です。条件は `u1`、つまり `bool` でなければなりません。

```vaak
let abs := if (n < 0) 0 - n else n fi;

if (score >= 90) grade := 1;
elif (score >= 60) grade := 2;
else grade := 3;
fi;
```

各分岐は一つの式です。複数の式を一つの分岐に置くなら括弧で一領域にまとめます。

```vaak
if (ready) (prepare(); run()) else wait() fi;
```

分岐に `{}` を付けると、単なる見た目のグループではなく、新しいスコープと脱出段ができます。
局所宣言が必要な場合には使えますが、`break` の届く先も一段変わるので意識して使ってください。

`else` が無く条件が偽なら paradox です。値が要る場合は `??` で既定値を与えます。

```vaak
let chosen := if (available) candidate fi ?? fallback;
```

### `while`、`nfor`、`loop`

`while` の条件は整数で、0 以外の間だけ繰り返します。本体には値を残せません。

```vaak
while (n > 0) {
    total += n;
    n -= 1;
};
```

`nfor` の第三引数は終値ではなく反復回数です。回数は `i64` で、0 以下なら 0 周です。ループ変数の
型は開始値の型になり、増加時に型の幅を越えれば通常の整数演算と同じく折り返します。

```vaak
nfor (i, 5, 3) {
    use(i);              % i は 5, 6, 7
};
```

正常終了した `while` と `nfor` は反復回数を返します。0 周なら値が一つも生まれないので paradox
です。回数が不要なら、上の例のようにループ全体へ `;` を付けます。

`loop { ... }` は無限ループです。通常は `break` で終わらせます。

### `break` と `continue`

`break` は現在の脱出段を終結させ、`continue` はループの次の周回を再開します。

```vaak
loop {
    if (done) break result; fi;
    step();
}

nfor (i, 0, n) {
    if (skip(i)) continue; fi;
    consume(i);
};
```

`break value` は一段を抜けて、その段の値として `value` を置きます。`break break value` は二段を
抜けます。動的な段数には `$repeat(break, n)` を使えます。段数は値の引数ではないため、
`break 5` は「5 段抜ける」ではなく「一段抜けて値 5 を置く」です。

脱出は関数本体というフレームで止まります。フレームを越える高度な制御には `outward` が
ありますが、呼び出し側の段構造に依存し、STEEL では未対応です。通常の早期 return には、
前節の `$return` のように現在の関数本体までを抜ける作用素式を使ってください。

### `switch`

`switch` は上から順に腕を照合し、最初に一致した腕だけを評価します。

```vaak
let points := switch (rank)
    case 1 => 100
    case 2 => 50
    case 3 => 25
?? 0;
```

閉じる予約語はありません。次の `case` 以外が現れたところで終わります。腕と次の `case` の間に
裸の `;` は置けません。最後の腕に続く `;` は腕ではなく `switch` 全体を捨てます。腕の中で値を
捨てたい場合は `(action();)` と括弧で囲みます。

入れ子の `switch` は内側が後続の `case` を読むため、括弧で終端を示します。

```vaak
switch (x)
    case 1 => (switch (y) case 2 => 20)
    case 3 => 30
```

どの腕にも一致しなければ paradox です。`??` を直後に置くと `switch` 全体の既定値になります。

## 7. 別名と権限

`:=` は値を深く複製します。`&=` は名前を既存のセルへ結び付け、複製しません。

```vaak
var data := [1, 2, 3];
var view : i64 array alias &= data;
view[0] := 9;
data[0]                         % 9
```

別名は値ではなく束縛の形です。次の制限があります。

- `&=` の右辺に置けるのは名前だけです。`&= data[i]` や `&= p.x` は書けません。
- `alias` 引数へ渡せるのも名前だけです。必要なら先に名前へ束縛します。
- 同じ呼び出しで同じセルへ届く別名を二つ渡せません。異なると証明できない場合も拒否されます。
- `var` の別名は `other &= target;` と指し直せます。`:=` は指す先のセルへ値を書きます。
- 権限を増やせません。`let` から `var` の別名は作れません。
- `const` の別名は作れますが、その間は元の名前を含むすべての経路からセルが凍結されます。
- 別名は内側の関数へ渡せますが、内側のセルを指す別名として外へ返せません。

非 `alias` 引数の深い複製と、`alias` 引数の非複製は署名から見分けられます。集合体が大きい場合は
性能上も重要です。

## 8. ホスト連携

### 値を公開する

Rust のホストは `Host` に名前を登録してソースを実行します。単純な値には
`expose_value` が使えます。

```rust
use vaak::host::{Host, Outcome};
use vaak::value::Value;

let mut host = Host::new();
host.expose_value("counter", Value::I64(1));

let outcome = host.run("counter += 41; counter");
match outcome {
    Outcome::Value(v) => assert_eq!(v.as_int(), Some(42)),
    other => panic!("{other:?}"),
}
```

独自の外部状態を見せる場合は `HostBinding` を実装し、`type_of`、実行前の `read`、実行後の
`write` を定義します。現在の界面は値全体の写しを渡し、走り終わってから書き戻す形です。

ホストが公開した値は最上位のスコープだけから見えます。関数の中で使う場合は、`alias` 引数で
明示的に受け取ります。

```vaak
fn read_second(regs : i32 array alias) {
    regs[1]
} -> i32;

let value := read_second(count);   % count はホストが公開した名前
```

これにより、関数がホスト状態へ触れることと、複製費用が署名に現れます。

### 呼べる名前を公開する

ホスト関数には `HostFn` を実装し、引数と返り値の型を `HostSig` で宣言します。

```rust
use vaak::ast::{HostSig, ValueType};
use vaak::host::{Host, HostFn};
use vaak::value::Value;

struct Add;

impl HostFn for Add {
    fn sig(&self) -> HostSig {
        HostSig {
            params: vec![ValueType::I64, ValueType::I64],
            ret: Some(ValueType::I64),
        }
    }

    fn call(&mut self, args: &[Value]) -> Option<Value> {
        Some(Value::I64((args[0].as_int()? + args[1].as_int()?) as i64))
    }
}

let mut host = Host::new();
host.expose_fn("add", Box::new(Add));
let outcome = host.run("add(20, 22)");
```

`ret: None` のホスト関数は値を置かないため、Vaak 側では `host_action();` と結果を捨てます。
呼べる名前はセルではないので、公開値と違って関数本体からも呼べます。

現在の実装はホスト関数を同期呼び出しします。再入のための中断・再開界面は設計済みですが、まだ
実装されていません。再入を前提にホスト関数から同じ実行器を呼び直さないでください。

### 実行結果

`Host::run` は `Outcome` を返します。

| 結果 | 意味 |
|---|---|
| `Value` | 最上位に値が残った |
| `Empty` | 最上位に何も残らなかった |
| `Paradox` | 消費されなかった paradox。発生位置を含む |
| `Static` | 構文、名前、領域、権限、型などの静的エラー |
| `Runtime` | 実行時エラー。位置を含む |

`Host::check` は既定で `true` です。検査器を通していないプログラムの挙動は言語仕様で保証されない
ため、信頼できない入力に対して無効にしないでください。`Host::use_vm = true` とすると、木を辿る
参照実装の代わりにバイトコード VM を使います。

## 9. ツールと実装範囲

### 実行系

| 実行系 | 使い方 | 現在の範囲 |
|---|---|---|
| `vaak` | `vaak file.vaak` | 木を辿る参照実装。中核の基準 |
| バイトコード VM | Rust から `Host::use_vm = true` | 参照実装と差分試験される。`f80` 以外の実装済み機能 |
| STEEL | `steel file.vaak` | LLVM IR とネイティブ実行ファイルを生成する部分実装 |
| Portable | WASI 実行ファイル、または素の WASM C ABI | VM を使う移植用入口 |

`f80` は STEEL 方言だけの型で、木を辿る実装と VM は明示的に拒否します。
木を辿る実装と VM に共通して残る既知の穴は、`str` を `u8 array` へ剥がす構築と、集合型を
包んだラップ型への組み込みメソッド転送、および `str` の `.insert()` / `.remove()` です。
いずれも設計判断にはありますが、現時点では実装済みの機能として扱わないでください。

### STEEL

```console
cargo run --release --bin steel -- examples/vaak/01-探索.vaak
cargo run --release --bin steel -- examples/vaak/01-探索.vaak --emit-ir
```

通常実行では `.ll` を作り、`clang -O2` で実行ファイルにします。`--emit-ir` は LLVM IR を
標準出力へ出します。`-o 名前` で実行ファイル名を指定できます。

現在の STEEL は、整数、`f32`、`f64`、`f80`、関数、制御、静的に畳める `flow`、配列、`str`、
`map`、`hash`、入れ子の集合体、構造体、ラップ型、別名、複合代入、適用できる集合型の `.len()`、
`.push()`、`.pop()`、`.clear()`、`.insert()`、`.remove()`、`.has()`、`.keys()` を扱います。

次はまだ扱いません。

- `str` の `.utf8_len()`、`.utf8_at()`、`.utf8_valid()`
- `outward`
- 実行時に段数が決まる `$repeat`
- 被演算子を伴う `continue`
- 利用者定義のメンバ関数
- ホスト界面

未対応の構文は、異なる意味のコードを生成せず、STEEL エラーとして拒否されます。

STEEL の現在のアリーナは関数境界でまとめて戻します。関数内のループが集合体を繰り返し確保する
プログラムでは、各周回でまだ場を戻せず、使い切ると終了コード 70 で止まります。

### Portable vaak

WASI 版は標準入力からソースを読みます。

```console
cargo build --release --target wasm32-wasip1 --bin portable
wasmtime target/wasm32-wasip1/release/portable.wasm < program.vaak
```

値が残れば表示し、整数として読める値なら下位 8 ビットを終了コードにします。それ以外の値と、値が
残らない場合の終了コードは 0 です。この解釈は Vaak の言語意味論ではなく、WASI 用ホストの約束です。

素の WASM 版は `vaak_alloc`、`vaak_run`、`vaak_last_output`、`vaak_free` という C ABI を公開し、
`wasm-bindgen` を必要としません。詳しい呼び出し約束は [`src/portable.rs`](../src/portable.rs) に
あります。

### 言語サーバと編集器

```console
cargo install --path .
```

`vaak-lsp` は標準入出力で話す言語サーバです。構文・名前・領域・型の診断、意味トークン、記号一覧、
説明、補完を提供します。Zed と VS Code の拡張は [`editors/`](../editors/README.md) にあります。

- Zed: `editors/zed` を開発拡張として入れます。色分けは tree-sitter、意味は `vaak-lsp` が担当します。
- VS Code: `editors/vscode` で `npm ci`、`npm run compile` を実行します。配布用 VSIX は
  `npm run package:vsix` で作れます。

### 主な演算子

強いものから大まかに並べます。

| 種類 | 演算子 |
|---|---|
| 呼び出し・アクセス | `f(...)` `a[i]` `x.member` |
| 前置 | `+` `-` `!` |
| 乗除 | `*` `/` `mod` |
| 代替 | `??` |
| 加減 | `+` `-` |
| シフト・ビット | `<<` `>>` `&` `^` `|` |
| 比較 | `<` `<=` `>` `>=` `==` `!=` |
| 短絡論理 | `&&` `||` |
| パイプ | `|>` |
| 脱出 | `break` `continue`、`$名前` |
| 代入 | `:=` `&=` と各種複合代入 |
| 捨てる | `;` |

`!` は `u1` では論理否定、整数ではビット反転です。`&&` と `||` は短絡します。比較と代入は
非結合なので、`a < b < c` や `a := b := c` は静的エラーです。

式の厳密な結合は [形式構文](vaak/16-形式構文.md) の束縛力表が一次資料です。ただし、後から
決まった `wrap`、`true` / `false` / `bool`、`f80`、利用者定義メンバ関数、`hash`、
浮動小数の鍵については、[設計判断](vaak/decisions.md) の S-1、S-2、C-97、S-20、C-98、
C-99 も併せて確認してください。
