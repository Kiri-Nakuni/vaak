## 1. 領域を作る記法

| | 領域 | スコープ | 脱出段 |
|---|---|---|---|
| `( E )` | ○ | × | × |
| `{ E … }` | ○ | ○ | ○ |
| 演算子の被演算子位置 | ○ | × | × |
| `if` の分岐 | ○ | × | × |

**`( )` は囲むだけ。`{ }` は三つ全部を作る。**

```
1 / 0 ?? 42          → 42
( 1 / 0 ) ?? 42      → 42。( ) は領域を作るだけなので ?? は届く
( break ) ?? 42      → 無効。?? は値の演算子であり、脱出は値ではない
```

分岐で複数の式を書きたいなら `( )` を使う——`{ }` は段を増やす（C-57）。

```
if (c) ( a; b ) fi;        段は増えない
if (c) { a; b } fi;        段が増える。中の break は { } を抜けるだけ
```

## 2. 値・虚無・paradox

1. **領域は終結した時点で値を持つ**
2. **内界面に何も置かれていない**か、**内界面に置かれた値が paradox** であるなら、
   **外界面は paradox**
3. paradox は **`;` で潰す**（内界面を空にする）か、**`??` で消す**（値に置き換える）
   かしなければならない

### 「何も残っていない」について

この言語における**「何も残っていない」の意味は特異である**——値が無いのではなく、
値が置かれる場所そのものを占めていない。通常の言語の `void` や `null` とは別のものである。

**そのため、我々はこれに名前を振っている。** ただし通例の理解には必須ではないので、
**付録に送る。規範の規則はこの語を使わずに書ける**（C-44）。

> **領域が paradox を持って終結したら、その時点でエラーである。**
> **終結を撤回できるのは `??` だけ。例外は無い。**

**終結は二段階ある**——`??` の前に起きるものと、後に起きるもの。
`??` が介入できるのはその間だけである（C-46）。

### 実行と評価

| | |
|---|---|
| **評価** | 式が自分の領域で値になること |
| **実行** | 外界面に置かれた作用が起きること |

`break break 2` では、**外側の `break` が評価され**（脱出が起きる）、
**内側の `break 2` が外界面で実行される。**

被演算子が**値なら、ここで評価されて置かれる**（`break y` の `y` はスコープを出る前に読まれる）。
**作用素式なら、外界面で実行される。**

### paradox を産むもの

0 除算／配列の範囲外／写像の欠損キー／0周のループ／`else` の無い `if` で条件が偽／
どの腕にも当たらない `switch`／剥がされたホスト別名／宣言／空の領域／`break` 自身

### エラーは三種

| | 種類 | |
|---|---|---|
| **1** | **静的** | **領域に値が複数ある**。走らせずに数えられる |
| 2 | 実行時（値） | 消費されなかった paradox。ホストは**発生点**を受け取る |
| 3 | 実行時（制御） | フレームを越える脱出 |

**静的検査は到達可能性を問わない**（C-51）。実行されない箇所も検査する。

**標準実装は、検査を通したプログラムを受け取ることを前提とする**（C-51）。
インタプリタは型を**解決する**（注釈を読んでリテラルの型を決める）が、**検査はしない**。

C-44（ループ本体に何も残らない）は **1 を周回数を待たずに捕らえる規則**である。

**最上位の外界面は Vaak の意味論ではない**（C-31）。
内界面に何も置かれずに終わればホストに委ねる——POSIX Vaak では `exit 0`。

## 3. 集合体

```
構築      型 ( 引数 )          型に括弧を付ければ、その型の値ができる（C-52）
          Point ( x := 1, y := 2 )      構造体。欄は名前で
          i64 array ( 10, 0 )           長さ 10、初期値 0
          str i64 map ( )               空の写像

配列      [ 1, 2, 3 ]         リテラル
          a[i]                添字。範囲外は paradox
          a.len()             現在の長さ。配列は動的（C-53）
写像      ( "a" => 1, … )     リテラル
          m[k]                欠損キーは paradox
文字列    "…"                 u8 array。添字はバイト
構造体    p.x                 欄へのアクセス
```

- **`.` と `[]` はアクセスであり、複製しない**（C-20）
- **束縛が複製する。複製は深い**（C-6、C-33）
- 反復子は無い。**言語が知る列は配列だけ**（C-8）
- **`&=` の対象は名前だけ**（C-53）。`&= a[i]` も `&= p.x` も書けない。
  だから配列が動的でも別名が宙に浮かない

## 4. 全体像

```
%{ 例：最も近い点を探す }%

struct Point {
    var x : i64 := 0;
    var y : i64 := 0;
};

fn Point.dist2 (self, other : Point alias) {
    let dx := self.x - other.x, dy := self.y - other.y;
    dx * dx + dy * dy
} -> i64;

fn nearest (ps : Point array alias, q : Point alias) {
    var best := 0, best_d := ps[0].dist2(q);
    nfor (i, 1, ps.len() - 1) {
        let d := ps[i].dist2(q);
        if (d < best_d) { best := i; best_d := d; } fi;
    };
    best
} -> i64;

fn gcd (a : i64, b : i64) {
    if (b == 0) a else gcd(b, a mod b) fi
} -> i64;

fn digit_sum (n : i64) {
    var s := 0, m := n;
    while (m) {
        s += m mod 10;
        m /= 10;
    };
    s
} -> i64;

fn find (a : i64 array alias, x : i64) {
    nfor (i, 0, a.len()) {
        if (a[i] == x) $return i; fi;
    }
} -> i64;
```
